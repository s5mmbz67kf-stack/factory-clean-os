# Factory Clean OS — גרסת ענן

מערכת Next.js המחוברת ל-Supabase ומיועדת לפריסה ב-Vercel.

## מה כבר בנוי

- כניסת מנהל באמצעות אימייל וסיסמה.
- כניסת עובד באמצעות מספר טלפון וקוד אישי בן 4 ספרות.
- הוספת עובד מתוך המערכת והגדרת אחוז רגיל ואחוז מידרג.
- הוספת עבודה על ידי מנהל או עובד.
- עבודה שעובד מזין נכנסת כ"ממתינה לאישור" ומופיעה אצל המנהל בזמן אמת.
- חישוב אוטומטי של שכר העובד ושל הסכום שנשאר לפקטורי.
- סכום קבוע או אחוז מיוחד לעבודה מסוימת.
- כרטיס לקוח מסודר בתוך טופס העבודה.
- לקוחות, עבודות, תשלומים ויתרה לעובד.
- ייבוא לקוחות מקובץ CSV.
- כל חלון ניתן לסגירה ב-X, בביטול, בלחיצה מחוץ לחלון או במקש Esc.
- התאמה לטלפון ולמחשב, כולל אפשרות הוספה למסך הבית.

## משתני סביבה שחייבים להגדיר ב-Vercel

```env
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...
SUPABASE_SECRET_KEY=...
```

`SUPABASE_SECRET_KEY` הוא המפתח שמתחיל ב-`sb_secret_`. הוא משמש רק בשרת ליצירת משתמשי עובדים. אין להכניס אותו לקובץ קוד, ל-GitHub או לדפדפן.

אפשר להשתמש במקום זאת במפתח הישן תחת השם:

```env
SUPABASE_SERVICE_ROLE_KEY=...
```

## העלאה ל-GitHub

1. צור Repository חדש ופרטי בשם `factory-clean-os`.
2. חלץ את קובץ ה-ZIP.
3. העלה ל-Repository את **התוכן שבתוך התיקייה**, כך ש-`package.json` יהיה בשורש.
4. אל תעלה קבצי לקוחות או קבצים שמכילים מפתחות.

## העלאה ל-Vercel

1. היכנס ל-Vercel ולחץ `Add New` ואז `Project`.
2. בחר את ה-Repository `factory-clean-os` ולחץ `Import`.
3. Framework Preset אמור להיבחר אוטומטית כ-Next.js.
4. באזור Environment Variables הוסף את שלושת המשתנים שלמעלה.
5. לחץ `Deploy`.

## לאחר הפריסה

1. היכנס למערכת באמצעות חשבון המנהל שיצרת ב-Supabase.
2. הוסף עובד אחד לבדיקה.
3. פתח את כתובת המערכת בגלישה פרטית והיכנס כעובד עם הטלפון והקוד שלו.
4. העובד יזין עבודה; אצל המנהל תופיע התראה והעבודה תחכה לאישור.
5. לאחר האישור, החישובים והיתרה יתעדכנו אוטומטית.

## ייבוא הלקוחות

מתוך מסך `לקוחות`, לחץ `ייבוא לקוחות מ-CSV` ובחר את הקובץ שסופק בנפרד. המערכת משווה מספרי טלפון ומדלגת על כפילויות ברורות.

## אבטחה

המידע מוגן באמצעות Supabase Auth ו-Row Level Security:

- מנהל רואה ומנהל הכול.
- עובד רואה רק את רשומת העובד שלו, את עבודותיו, את התשלומים שלו ולקוחות הקשורים לעבודותיו.
- המפתח הסודי משמש רק ב-API שרץ בצד השרת.
